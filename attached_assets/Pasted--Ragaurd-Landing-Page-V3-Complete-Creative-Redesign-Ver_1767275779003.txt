# Ragaurd Landing Page V3 - Complete Creative Redesign (Version 2)

You are designing Version 3 of the landing page for Ragaurd, a B2B SaaS product that provides AI security for voice agents. You have FULL creative control over layout, structure, animations, and copywriting. Create something bold, premium, and memorable.

## THE PRODUCT: Ragaurd

Ragaurd is a security layer for AI voice agents. It protects against:
- **Prompt injection attacks** - Hidden instructions that override system prompts
- **Jailbreaking** - Social engineering to bypass safety guidelines  
- **Data exfiltration** - Attackers extracting system prompts and business logic
- **Deepfake audio** - Synthetic voice cloning to impersonate authorized users
- **Compliance exposure** - PII/PHI handling that creates regulatory liability

### Core Features
1. **Text Defense** - 6-layer detection: pattern matching, semantic analysis, embedding similarity, LLM guard, context validation, output filtering. 99.5% detection rate.

2. **Audio Defense** - Real-time deepfake detection using AASIST-L and LCNN models. 0.83% equal error rate. Identifies synthetic voices before they reach your agent.

3. **Red Team Testing** - Automated security scanning with 10,000+ attack vectors. Find vulnerabilities before attackers do.

### Pricing Tiers (keep these exact prices)
- **Free**: $0/month - 500 text requests, 1 API key, community support
- **Starter**: $79/month - 25,000 text requests, 3 API keys, email support, <500ms latency
- **Pro**: $249/month - 150,000 text requests, 50,000 audio requests, 1,000 red team tests, 10 API keys, priority support, <200ms latency (MOST POPULAR)
- **Business**: $649/month - 500,000 text requests, 200,000 audio requests, 10,000 red team tests, 25 API keys, dedicated support, <100ms latency

### Key Stats (use these or similar)
- 99.53% attack block rate
- <200ms average latency
- 6 defense layers
- 5 minute integration
- 10,000+ attack vectors tested
