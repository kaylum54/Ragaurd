Background: White with Subtle Dynamics
The primary background is WHITE or off-white. Include a tasteful dynamic element such as:

Slowly morphing gradient blobs (navy-100 to navy-200 tones, very subtle)
Floating geometric shapes with gentle parallax (navy-50 opacity)
Soft animated grain or noise texture
Gentle wave or mesh animation
Subtle dot grid with soft pulse effect
DO NOT include:

Radar/scanning effects
Pulsing threat indicators
Glitch effects
Particle systems
Anything that looks "hacker" or "cyber"
Dark mode aesthetic
Neon glows
The dynamic background should feel like Stripe, Linear, or Vercel - premium, subtle, almost unnoticeable but adds depth.

Example approach:

.subtle-gradient-bg {
  background: linear-gradient(135deg, #ffffff 0%, #f0f7ff 50%, #ffffff 100%);
  position: relative;
}

.subtle-gradient-bg::before {
  content: '';
  position: absolute;
  inset: 0;
  background: 
    radial-gradient(ellipse 100% 80% at 20% 20%, rgba(59, 124, 184, 0.06) 0%, transparent 50%),
    radial-gradient(ellipse 80% 60% at 80% 80%, rgba(26, 58, 92, 0.04) 0%, transparent 50%);
  animation: subtle-shift 30s ease-in-out infinite;
}

@keyframes subtle-shift {
  0%, 100% { opacity: 1; transform: scale(1); }
  50% { opacity: 0.8; transform: scale(1.05); }
}

Typography: Professional & Smart
This is critical. Typography must feel premium and intelligent.

Font pairing options (pick one):

Inter (body) + Inter (headings) - Clean, modern, versatile
Söhne or equivalent (body) + Söhne (headings) - Stripe-like
IBM Plex Sans (body) + IBM Plex Sans (headings) - Technical credibility
Untitled Sans or similar geometric sans
Typography rules:

Headlines: Bold or Semibold, tight letter-spacing (-0.02em to -0.03em)
Body: Regular weight, generous line-height (1.6-1.7)
Maximum body text width: 680px for readability
Clear hierarchy: Display > H1 > H2 > H3 > Body > Caption
Navy-950 for primary text on white backgrounds
White for text on navy backgrounds
